Measurement Fundamentals

What examiners repeatedly ask

  • Accuracy = closeness to the true value.
  • Precision = closeness of repeated readings to each other.
  • Repeatability = same reading under identical conditions.
  • Sensitivity = output change per unit input.
  • Resolution = smallest detectable input change.
  • Readability = ease of reading the instrument.

The most common confusion: accuracy vs precision

  • High precision + low accuracy = repeated wrong readings.
  • High accuracy + low precision = average near true value but scattered readings.
  • In competitive exams, “most important characteristic” → accuracy.

Sensitivity and range

  • Sensitivity is inversely proportional to range.
  • For a fixed scale length:
    • Large range → low sensitivity.
    • Small range → high sensitivity.

Gauges and Gauge Blocks

Slip gauges (gauge blocks)

  • Precision length standards.
  • Made of hardened steel, carbide, ceramic, or quartz.
  • Joined by wringing.

Wringing

  • Molecular attraction + surface tension.
  • Requires extremely flat and smooth surfaces.

Standard cross-section

  • Above 10 mm: 35 × 9 mm.

GO and NO GO gauges

Principle

  • GO gauge checks maximum material condition (MMC).
  • NO GO gauge checks minimum material condition (LMC).

Taylor’s principle (extremely important)

Wear allowance

  • Provided only on the GO gauge.
  • Reason: GO gauge is used more frequently.

Limits, Fits, and Tolerances (Highest-Weight Topic)

Basic terminology

  • Basic size = nominal size.
  • Actual size = measured size.
  • Limit size = maximum or minimum permissible size.
  • Tolerance = upper limit − lower limit.
  • Deviation = difference from basic size.

Hole basis system

Key property

  • Lower deviation of hole = zero.

Therefore: Minimum hole size = basic size.

Example: H7

  • Lower deviation = 0.
  • Tolerance zone lies above basic size.

Shaft basis system

  • Upper deviation of shaft = zero.
  • Maximum shaft size = basic size.

Unilateral vs bilateral tolerance

Unilateral

  • Entire tolerance on one side of basic size.
  • Examples:
    • $50^{+0.02}_{0}$
    • $50^{0}_{-0.02}$

Bilateral

  • Tolerance on both sides.
  • Example: $50 \pm 0.02$

Allowance

Definition

Difference between maximum material limits of mating parts.

For clearance fit: Allowance = minimum clearance.

For interference fit: Allowance = maximum interference.

Clearance, transition, and interference fits

FitCondition
ClearanceHole always larger
TransitionMay clear or interfere
InterferenceShaft always larger

Interference fit condition

Lower limit of shaft > upper limit of hole.

Fit notation (must memorize)

Example: 50 H7/g6

  • 50 = basic size.
  • H7 = hole.
  • g6 = shaft.

Surface Roughness and Texture

What roughness actually measures

  • Micro-irregularities on a surface.
  • Different from flatness.
  • Roughness = local texture.
  • Flatness = overall geometry.

Important parameters

ParameterMeaning
RaArithmetic mean roughness
RqRMS roughness
RpMaximum peak height
RzAverage peak-to-valley
tpMaterial ratio (%)

Ra formula

$$\text{Ra} = \frac{\sum |\text{profile areas}|}{\text{sampling length}}$$

Area method shortcut

  • Add all areas above datum.
  • Add all areas below datum.
  • Use total absolute area.
  • Apply magnification corrections.

Optical Metrology

Optical flat

Material

  • Quartz (fused quartz).

Principle

  • Interference of monochromatic light.

Use

  • Flatness testing.

Interference facts

  • Bright to next bright = $\lambda$.
  • Dark to next dark = $\lambda$.
  • Bright to adjacent dark = $\lambda/2$.

Fractional coincidence method

  • Used for slip (end) gauge measurement.

Autocollimator

Principle

  • Reflection of a collimated monochromatic light beam.

Key relationship

Mirror tilt = $\theta$   &implies;   Reflected beam deflection = $2\theta$

Applications

  • Small angle measurement.
  • Straightness.
  • Flatness.
  • Parallelism.
  • Squareness.
  • Machine alignment.
⚠️ Exam trap: Primary use = angle measurement.

Sine Bar and Angle Measurement

Sine bar

Specification

  • By centre distance between rollers.

Surface finish

  • Working surfaces ≈ 0.2 μm.

Formula

$$\theta = \sin^{-1}\left(\frac{h}{L}\right)$$

Where $h$ = slip gauge height, $L$ = roller centre distance.

Uses

  • External taper.
  • Precise angle setting.
  • Angle measurement.

Angle gauges

Degree series:

  • 1°, 3°, 9°, 27°, 41°

Bevel protractor

  • Acute angle attachment is provided with bevel protractor.

Strain Measurement

Resistance strain gauge

Principle

  • Resistance changes proportional to strain.

Gauge factor

$$\text{GF} = \frac{\Delta R / R}{\varepsilon}$$

Example

$\text{GF} = 2.1,\quad R = 50\ \Omega,\quad \varepsilon = 0.001 \implies \Delta R = \mathbf{0.105\ \Omega}$

Mechanical strain gauge

  • Measures:
    • Static strain.
    • Quasi-static strain.

Not suitable for: High-frequency dynamic strain.

Transducers and Instrumentation

LVDT

  • Measures linear displacement.
  • Output proportional to displacement.

Photoconductive cell (LDR)

  • Resistance changes with light intensity.

Piezoelectric transducer

  • Stress → electric charge.
  • Best for dynamic measurements.

Pressure and Flow Measurement

Dead weight tester

Purpose

  • Primary pressure standard.
  • Calibration of pressure gauges.

Formula

$$P = \frac{W}{A}$$

Electromagnetic flow meter

  • Induced voltage ∝ flow rate.

Variable head flow meters

  • Used for:
    • Liquids.
    • Gases.
