PART 1 — ⚙️ NC, CNC & DNC FUNDAMENTALS

1. NC vs CNC vs DNC

  • NC = programmed numerical instructions control machine movement.
  • CNC = NC + computer-based control, memory, editing and diagnostics.
  • DNC = computer/network system used to serve and coordinate multiple NC/CNC machines.

DNC system components

  • Dedicated computer + bulk memory + telecommunication lines are required for a DNC system.
  • Satellite computers in DNC serve a group of NC machines and can distribute processing/control functions.
  • DNC = Computer + Memory + Communication + Multiple machines.

2. CNC Advantages over NC

  • Easy operation compared with conventional NC.
  • Programs can be stored and recalled easily.
  • Reprogramming/editing is easier in CNC than NC.
  • CNC provides self-diagnostic features.
  • CNC offers higher flexibility than NC.
  • CNC generally has lower data-reading/interpretation errors.
  • Metric ↔ inch conversion is possible in CNC (Commands: G20 = inch, G21 = mm).
⚠️ MCQ Trap: “Reprogramming in CNC is more difficult than NC” → FALSE

PART 2 — 🎯 CNC AXES & CONTROL

3. CNC Axis Convention

CNC lathe

  • X-axis → cross/radial movement of cutting tool (Controls Diameter).
  • Z-axis → longitudinal movement parallel to spindle axis (Controls Length).
  • Positive/negative Z direction is defined according to machine coordinate convention; movement towards/away from headstock is associated with Z-axis travel.
  • Y-axis does not control the job; where provided, it represents an additional tool-axis direction.
  • X, Y, Z are linear axes; A, B, C are rotary axes.
CNC Lathe Shortcut: X → Diameter • Z → Length

4. CNC Control Types

ControlTypical application
Point-to-point (PTP)Drilling, punching, spot welding
Straight-lineTurning, facing, simple tapering
Contouring / continuous pathComplex profiles and surfaces
  • Straight-line control in X and Z → turning + facing + taper turning.
  • Simultaneous X–Y–Z control → 3D contour/complex-shape machining.
  • Complex shapes require coordinated simultaneous axis motion.
CNC Lathe Motion Combinations:
• X only → Facing
• Z only → Turning
• X + Z simultaneous → Taper turning
• Synchronized spindle + axis → Threading

PART 3 — 🧭 CNC INTERPOLATION

5. Interpolator

  • Interpolator coordinates feed rates/motion of multiple axes.
  • Calculates intermediate points needed to generate the programmed tool path.
  • Used for linear, circular and contouring interpolation.
  • Does not directly perform spindle ON/OFF or coolant control.
Key Distinction:
• Interpolator → Axis coordination & feed rate management
• Spindle controller → Spindle speed
• M-functions → Auxiliary machine functions

PART 5 — 🔄 FEED DRIVES, SPINDLE DRIVES & ENCODERS

9. CNC Feed Drive

  • CNC milling machine feed drives are generally provided by servo motors.
  • Servo motors provide precise position + speed control with closed-loop feedback.
  • Stepper motors are common in simpler/open-loop systems.
  • Feed drive = axis movement; spindle drive = spindle rotation.

10. Encoders

  • Encoder = feedback sensing device for position and speed measurement.
  • Linear encoder → table/axis linear position.
  • Rotary encoder → angular position and speed.
  • Spindle encoder → spindle speed and angular position.
  • Absolute encoder → retains absolute position after power loss.
  • Incremental encoder → pulse count gives movement; pulse frequency gives speed.
⚠️ MCQ Trap: Encoder applications include spindle speed + spindle position + table position (all three are valid).

PART 6 — ⚙️ STEPPER MOTORS

11. Stepper Motor Fundamentals

  • Rotates through discrete angular steps for input pulses.
  • 1 pulse → 1 step.
  • Number of pulses → angular position.
  • Pulse frequency → rotational speed.
  • Continuous rotation is achieved when a continuous pulse train is applied.
  • Statement: “stepper motor cannot give continuous rotation” → FALSE.

Variable Reluctance Stepper Motor

  • Rotor is soft iron/toothed, without permanent magnet excitation.
  • Low rotor inertia → quick response (less sluggish).
  • Provides relatively small step angles.

PART 7 — 🏭 MACHINING CENTRE

12. Machining Centre

Advanced CNC machine designed for multiple operations in one single setup. Logical development beyond basic NC machine tools.

  • Automatic Tool Changer (ATC)
  • Tool magazine
  • Automatic indexing / pallet changing system
ATC Mechanism Sequence: T-code selects tool in magazine → M06 executes physical tool change. Reduces non-productive setup time.

PART 8 — 💻 NC PART PROGRAMMING & APT

13. APT Language

  • APT = Automatically Programmed Tools (High-level NC/CAM programming language).
  • Used to describe part geometry and tool motion.
APT PROGRAMMING WORKFLOW:
APT Program Source ──► APT Processor ──► Cutter Location (CL) Data ──► Postprocessor ──► Machine G/M Code

14. APT Macro & Geometry Syntax

$$\text{SYMBOL} = \text{MACRO} / \text{PARAMETERS}$$

Macro termination keyword = TERMAC.

  • Geometry keywords: POINT, LINE, CIRCLE. Motion: GOTO, GOFWD.
  • Modifier keywords: TANTO (tangent), INTOF (intersection), LFT TANTO (left tangent).
  • Example: L1 = LINE/P1, LFT TANTO C1

PART 9 — 🧮 DAC & CNC CONTROL ELECTRONICS

15. DAC Resolution Formula

$$1\text{ LSB} = \frac{V_{\text{FS}}}{2^n - 1}$$
Worked Exam Example:
For an 8-bit DAC ($n=8$) with full-scale voltage $V_{\text{FS}} = 6\text{ V}$:
$$1\text{ LSB} = \frac{6}{2^8 - 1} = \frac{6}{255} \approx \mathbf{0.0235\text{ V}}\quad (\mathbf{0.023\text{ V}})$$

PART 11 — 🧱 CAD MODELLING

20. Geometry vs Topology

  • Geometry → dimensions, coordinates, curves, surfaces, shape.
  • Topology → connectivity/relationships among vertices, edges and faces.
  • A solid model's completeness is defined by Geometry + Topology.

21. CSG / Boolean Operations

$$\text{Boolean Operations} = n - 1$$

For $n$ primitives combined into one solid (Union, Intersection, Difference). Example: 10 primitives require $10 - 1 = \mathbf{9}$ operations.

22. Mass Properties

  • Mass properties (volume, centroid, mass, moments of inertia) require a 3D solid model stored with geometry + topology.

PART 12 — 📐 CAD TRANSFORMATIONS & EXCHANGE

23. Scaling Transformations

  • Scale factor $k > 1$ → enlargement. $0 < k < 1$ → reduction.
  • Negative scale factor ($k < 0$) → Reflection / Mirroring combined with scaling.

24. IGES (Initial Graphics Exchange Specification)

  • Used for CAD data exchange between different software packages.
  • Uses a non-binary / text-based representation (ASCII formatted).

PART 17 — 🔄 CAD/CAM DATA TRANSLATION

34. Direct vs Indirect Translators

$$\text{Direct Translators} = n(n - 1) \quad \text{vs} \quad \text{Indirect Translators} = 2n$$
Exam Calculation (for $n = 7$ CAD Systems):
• Direct: $7(7-1) = \mathbf{42\text{ translators}}$
• Indirect (via neutral IGES format): $2(7) = \mathbf{14\text{ translators}}$

PART 18 — 🧮 CAPACITY & CIM BENEFITS

35. Capacity Formulas

$$\text{Utilization} = \frac{\text{Actual Output}}{\text{Design Capacity}} \times 100\% \quad \text{vs} \quad \text{Efficiency} = \frac{\text{Actual Output}}{\text{Effective Capacity}} \times 100\%$$

36. Benefits of CIM

  • Less direct labour • Less scrap and rework • Higher machine utilization.

46. Arc Centre Math Shortcut

$$\text{Check Radius}: r = \sqrt{(x - x_c)^2 + (y - y_c)^2}$$

For $P_1(15,10)$, $P_2(10,15)$, $r=5 \implies \text{Centre } (10,10)$.
