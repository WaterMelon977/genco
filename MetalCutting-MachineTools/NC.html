Numerical Control (NC), CNC, DNC, FMS and Machining Centres

This guide covers Numerical Control (NC), Computer Numerical Control (CNC), Distributed Numerical Control (DNC), basic CNC programming, axes and motion control, and the key FMS / machining-centre ideas that appear in AP Genco AE and related MCQs. The focus is on the actual study material: clear definitions, recurring exam traps, and the few facts that are repeatedly tested.

Quick-Reference Card

NC / CNC / DNC

  • NC uses punched tape or similar coded input; CNC stores the program in computer memory.
  • CNC is more flexible than NC, easier to reprogram, and can provide self-diagnostic features.
  • DNC uses one central computer to control multiple CNC machines.
  • In DNC, satellite computers help share the processing of large NC programs.
  • Adaptive control is used for automation and automatic adjustment of machining conditions.

Axes and Motion

  • In a CNC lathe, the X-axis controls cross motion of the cutting tool.
  • The Z-axis controls carriage travel towards or away from the headstock.
  • Basic CNC lathes do not have a Y-axis.
  • The interpolator coordinates feed rates of axes and generates intermediate points.
  • Point-to-point motion is used for discrete locations.
  • Continuous-path or contouring motion is used when the tool must follow a path while cutting.

Programming Codes

  • G02 = circular interpolation clockwise.
  • G21 = metric input in millimetres.
  • M02 = end of program.
  • M06 = tool change.
  • F-code = feed rate.
  • APT is used in CAM for NC machine tools.
  • Parametric programming uses variables to describe geometry.

Feedback and Drives

  • Encoders sense and control table position.
  • Servo motors are commonly used as feed drives in CNC milling machines.
  • Stepper motors move in fixed steps for each pulse.

CAD / CAM / FMS / Centres

  • The core product model in CAD/CAM is the geometric model.
  • Machining centres have an automatic tool changer (ATC) and a component indexing device.
  • Flexible manufacturing allows quick and inexpensive product changes.
  • AGVs are used for transporting work parts and tools in CIM.
  • CAD/CAM technology was initiated in the aerospace industry.

Core Theory

Fundamentals of NC and CNC

  • NC is machine-tool control using coded numerical data on tape, cards, or other input media.
  • CNC is advanced NC where a dedicated computer or microprocessor is built into the machine control unit.
  • CNC programs are stored in memory and can be edited more easily than NC programs.
  • DNC means a central computer controls multiple CNC machines.
  • NC is older and harder to edit; CNC is flexible and supports memory storage, editing, and simulation.
  • Both NC and CNC reduce the need for manual control during each cycle, but skilled programming is still required.
  • Closed-loop systems use feedback devices for position or velocity correction.
  • Open-loop systems do not use feedback, and stepper-motor systems are common examples.

Components of an NC / CNC System

  • Input device: tape reader in older NC, or keyboard, USB, network, or CAD/CAM transfer in CNC.
  • Machine Control Unit (MCU): the brain of the system, containing CPU, memory, data processing, and control functions.
  • Drive system: servo motors, stepper motors, or hydraulic or pneumatic actuators that move the axes.
  • Machine tool: the actual lathe, mill, drill, or similar machine whose motion is controlled.
  • Feedback devices: encoders, resolvers, or linear scales that send actual position or velocity back to the MCU.
  • Display unit: shows program, position, alarms, and machine status.

Types of NC / CNC Systems

  • Point-to-point (PTP): the tool moves to discrete programmed points; path control between points is not important.
  • PTP is used for drilling, boring, punching, and spot welding.
  • Continuous-path or contouring systems control the path while cutting.
  • Straight-cut control uses linear interpolation.
  • Contouring can use linear and circular interpolation for complex curves.
  • Modern CNC machines are often contouring systems with multi-axis capability.

Coordinate Systems

  • Absolute coordinate system (G90): every position is measured from a fixed datum.
  • Incremental coordinate system (G91): every position is measured from the previous position.
  • Absolute is easier to debug and safer because one error does not affect later points.
  • Incremental is useful for repetitive patterns and shorter programs.
  • Datum can be set at a corner, centre, or any convenient point on the workpiece.

Advantages, Limitations, Applications, Jigs and Fixtures

  • Advantages over conventional machining include higher accuracy, better repeatability, complex contours, reduced setup time, and consistent quality.
  • CNC also supports easy program storage, reuse, and long-duration operation.
  • Limitations include high initial cost, maintenance cost, and the need for skilled programmers.
  • CNC is not ideal for very small batches or very simple jobs.
  • Applications include aerospace, automotive, die and mould making, medical implants, and precision components.
  • Jigs guide the cutting tool, for example through drill bushes.
  • Fixtures hold the workpiece rigidly in the correct position.
  • Jigs guide the tool; fixtures do not guide the tool.

Examiner Traps

  • CNC does use a computer; saying it does not is wrong.
  • NC and CNC are not identical; CNC has memory, editing, and greater flexibility.
  • Not all NC systems are closed-loop; some are open-loop.
  • DNC means Distributed or Direct Numerical Control depending on usage, but in this syllabus it is the central-computer concept.
  • PTP systems do not machine complex contours.
  • Continuous path does not mean only circular interpolation; it includes linear and circular control.
  • Absolute coordinate systems do not measure from the previous point.
  • Incremental is not safer than absolute for general programming.
  • G90 is absolute and G91 is incremental.
  • Jigs and fixtures are not the same thing.
  • CNC does not eliminate tool wear.

NC / CNC / DNC Fundamentals

  • NC uses coded instructions and punched tape, while CNC stores programs in memory.
  • CNC is easier to reprogram than NC.
  • CNC can diagnose programs and has higher flexibility than NC.
  • Conversion of units is possible in CNC machines.
  • Punched tape belongs to NC machines.
  • DNC requires a dedicated computer, bulk memory, and telecommunication lines.
  • Satellite computers in DNC share the processing of large-size NC programs.
  • Adaptive control is used for automation.
  • A statement saying reprogramming in CNC is more difficult than NC is false.
  • A statement saying conversion of units in CNC is not possible is false.

Example:
Question pattern: Which of the following is not a true statement for CNC system?

(a) Operation of CNC machine is very easy relative to NC machine
(b) Programme can be easily called in CNC relative to NC
© Reprogramming in CNC is more difficult than NC system
(d) CNC machine has self-diagnostic features

Reasoning:

  1. CNC stores the program in memory, so reprogramming is easier, not harder.
  2. Options (a), (b), and (d) are true advantages of CNC.

Answer: ©

CNC Axes, Motion Control and Interpolator

  • X-axis controls cross motion of the cutting tool in a CNC lathe.
  • Z-axis controls carriage travel towards or away from the headstock.
  • Simple CNC lathes have no Y-axis.
  • The encoder is used to sense and control table position.
  • The interpolator coordinates feed rates of axes and generates intermediate coordinate positions.
  • Contouring is continuous-path positioning.
  • Complex shapes require simultaneous control of multiple axes.
  • Servo motors provide feed drives in CNC milling machines.

Example:
Question pattern: Which statements are correct for a CNC lathe?

  1. X-axis controls cross motion of cutting tool
  2. Z-axis controls travel of carriage towards or away from headstock
  3. Y-axis controls motion of the job
  4. X-Y-Z used for rotational movement of table

Reasoning:

  1. Statements 1 and 2 are correct.
  2. A basic CNC lathe has no Y-axis, so statement 3 is false.
  3. Statement 4 is false.

Answer: 1 and 2

Part Programming

  • G02 is circular interpolation clockwise.
  • G21 means millimetre input.
  • M02 means end of program.
  • M06 means tool change.
  • F-code gives feed rate.
  • APT is used in CAM for NC machine tools.
  • Parametric programming uses variables.
  • Binary coding is used in NC programming.

Example:
Question pattern: During execution of CNC part program block N020 G02 X45.0 Y25.0 R5.0, the tool motion will be:

Reasoning:

  1. G02 is clockwise circular interpolation.
  2. X, Y, and R define the end point and radius.

Answer: Circular interpolation clockwise

CAD / CAM / FMS and Machining Centres

  • The geometric model is the core product model in CAD/CAM.
  • Machining centres have ATC and component indexing devices.
  • Flexible manufacturing allows quick and inexpensive product changes.
  • In FMS, tools may be identified by bar code.
  • AGVs transport work parts and tools in CIM.
  • CAD/CAM began in the aerospace industry.
  • Transfer machines are both material-processing and material-handling machines.
  • Hard automation is also called fixed-position automation.

Example:
Question pattern: Which one has an automatic tool changing unit and a component indexing device?

(a) Machining center
(b) NC system
© CNC system
(d) DNC system

Reasoning:

  1. A machining centre is defined by ATC and component indexing.
  2. NC, CNC, and DNC describe control architecture, not this hardware combination.

Answer: (a) Machining center
