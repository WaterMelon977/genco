Balancing of Masses
High-Yield Exam Revision Guide | APGENCO AE • GATE • SSC JE

1. Static Balancing of Rotating Masses

A system of rotating masses is statically balanced when the resultant centrifugal force on the shaft is zero ($\sum \vec{F}_c = 0$). For masses rotating in a single plane, static balance is achieved by placing a single balance mass opposite to the unbalance vector.

$$\sum m_i r_i = 0 \quad \Longleftrightarrow \quad \sum m_i r_i \cos\theta_i = 0 \;\text{ and }\; \sum m_i r_i \sin\theta_i = 0$$
$m_i$: rotating mass ($\text{kg}$) $r_i$: radius of rotation ($\text{m}$) $\theta_i$: angular orientation ($\text{deg}$)
$$F_c = m \omega^2 r \quad [\text{N}]$$
$F_c$: centrifugal force ($\text{N}$) $\omega$: angular speed ($\text{rad/s}$)

2. Dynamic Balancing — Multi-Plane Systems

When masses rotate in different axial planes along a shaft, static balance alone is insufficient because unbalanced couples remain. Dynamic balance requires both force and couple polygons to close.

$$\text{Force Condition: } \sum m_i r_i = 0 \qquad \text{Couple Condition: } \sum m_i r_i l_i = 0$$
$l_i$: axial distance from Reference Plane ($\text{m}$)
⚠️ Exam Trap: Dynamic balance ALWAYS implies static balance. However, a statically balanced system is NOT necessarily dynamically balanced. Dynamic balancing of multi-plane systems requires a minimum of two balancing masses in two separate planes.

3. Balancing of Reciprocating Masses

Reciprocating masses (piston, wrist pin, part of conrod) cannot be completely balanced by rotating counterweights due to non-linear piston kinematics.

$$\text{Primary Inertia Force: } F_P = m_{\text{rec}} r \omega^2 \cos\theta \quad (\text{frequency } \omega)$$
$$\text{Secondary Inertia Force: } F_S = \frac{m_{\text{rec}} r \omega^2}{n} \cos 2\theta \quad (\text{frequency } 2\omega)$$
$n = l/r$: obliquity ratio (connecting rod length / crank radius)

4. Partial Balancing & Counterweight Calculations

To avoid creating excessive transverse unbalance, only a fraction $c$ (typically $c \approx 2/3 \approx 0.67$) of reciprocating mass is balanced.

$$\text{Equivalent Revolving Mass: } m_{\text{eq}} = m_{\text{rev}} + c \cdot m_{\text{rec}}$$
$$\text{Counterweight Requirement: } B \cdot b = m_{\text{eq}} \cdot r = (m_{\text{rev}} + c \cdot m_{\text{rec}}) \cdot r$$
$B$: balancing mass ($\text{kg}$) $b$: counterweight radius ($\text{m}$)

5. Multi-Cylinder & Locomotive Effects

In two-cylinder locomotives with cranks set at 90°, partial balancing creates three major dynamic effects:

Locomotive Effect Governing Formula Key Characteristics & Maxima
Hammer Blow $H = B b \omega^2 = c m_{\text{rec}} r \omega^2$ Max vertical force on rail. Wheel lifts off rail when $B b \omega^2 \ge W_{\text{static}}$.
Tractive Effort Variation $\Delta F_T = \pm \sqrt{2} (1-c) m_{\text{rec}} r \omega^2$ Fluctuation in horizontal pull along stroke line. Max at $\theta = 135^\circ, 315^\circ$.
Swaying Couple $C_{\text{sway}} = \pm \frac{a}{\sqrt{2}} (1-c) m_{\text{rec}} r \omega^2$ Rocking couple about vertical axis ($a$ = cylinder spacing). Max at $\theta = 45^\circ, 225^\circ$.
🔴 EXAM FOCUS: Locomotive cranks are set at 90° to ensure self-starting capability from rest in any stopping position. 90° V-twin engines achieve complete primary balance with a single counterweight $m$ at radius $r$.

6. Key Points to Remember

Exam Survival Checklist
  • Static Balance: $\sum mr = 0$ — 1 mass in 1 plane sufficient.
  • Dynamic Balance: $\sum mr = 0$ AND $\sum mrl = 0$ — minimum 2 masses in 2 separate planes.
  • Dynamic Balance $\Rightarrow$ Static Balance (Always). Converse is FALSE.
  • Reciprocating Forces: Primary $= m r \omega^2 \cos\theta$; Secondary $= m r \omega^2 \cos 2\theta / n$.
  • Partial Balance Fraction: $c \approx 2/3$. $Bb = (m_{\text{rev}} + c m_{\text{rec}}) r$.
  • Hammer Blow: $H = c m_{\text{rec}} r \omega^2$. Wheel lifts if $H \ge W_{\text{static}}$.
  • Tractive Variation: $\pm \sqrt{2}(1-c) m_{\text{rec}} r \omega^2$ at $\theta = 135^\circ/315^\circ$.
  • Swaying Couple: $\pm \frac{a}{\sqrt{2}}(1-c) m_{\text{rec}} r \omega^2$ at $\theta = 45^\circ/225^\circ$.
