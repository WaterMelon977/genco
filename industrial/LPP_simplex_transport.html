2.2 — Key Definitions & Master Concepts

  • Linear Programming Problem (LPP): Mathematical optimization technique to maximize or minimize a linear objective function subject to linear equality/inequality constraints and non-negativity restrictions.
  • Feasible Region: Intersection of all constraint half-planes including non-negativity conditions. Convex polygon in 2D space.
  • Extreme Point (Corner Point) Theorem: The optimal solution of an LPP, if it exists, MUST occur at a corner point (extreme point) of the feasible region.
  • Slack Variable (si≥0s_i \ge 0si​≥0): Variable added to a ≤\le≤ constraint to convert it into an equality (ai1x1+si=bia_{i1}x_1 + s_i = b_iai1​x1​+si​=bi​). Cost coefficient cs=0c_s = 0cs​=0.
  • Surplus Variable (si≥0s_i \ge 0si​≥0): Variable subtracted from a ≥\ge≥ constraint to convert it into an equality (ai1x1−si=bia_{i1}x_1 - s_i = b_iai1​x1​−si​=bi​). Cost coefficient cs=0c_s = 0cs​=0.
  • Artificial Variable (Ai≥0A_i \ge 0Ai​≥0): Dummy variable added to ≥\ge≥ or === constraints to form an initial identity matrix basis. Heavily penalized in objective (−M-M−M in Big-M method).
  • Special LPP Solution Cases:
    • Infeasible Solution: No common feasible region exists, OR artificial variable remains in final Simplex basis at positive value.
    • Unbounded Solution: Feasible region extends to infinity in improving direction, OR all pivot column entries are ≤0\le 0≤0 during ratio test.
    • Alternate (Multiple) Optima: Objective function line is parallel to a binding constraint, OR Cj−Zj=0C_j - Z_j = 0Cj​−Zj​=0 for a non-basic variable in optimal Simplex table.
    • Degenerate Solution: Tie in minimum ratio test causes a basic variable to become zero, OR number of transportation allocations <m+n−1< m + n - 1<m+n−1.
  • Transportation Problem: Special LPP class distributing items from mmm origins to nnn destinations at minimum total cost. Initial methods: North-West Corner, Least-Cost, Vogel’s Approximation (VAM - most efficient).
  • Assignment Problem (Hungarian Method): Special n×nn \times nn×n transportation problem assigning nnn jobs to nnn machines one-to-one.
  • Shadow Price (Dual Variable yiy_iyi​): Incremental change in optimal objective value per unit increase in resource bib_ibi​.

3.1 — LPP Formulation & Graphical Method

1. Concept Pointers
  • Assumptions: Linearity (proportionality + additivity), Divisibility, Certainty, Non-negativity.
  • Graphical Method Scope: Strictly limited to two decision variables (x1,x2x_1, x_2x1​,x2​).
  • Corner Point Procedure:
    1. Plot constraint lines as equalities on x1−x2x_1-x_2x1​−x2​ axes.
    2. Shade feasible region satisfying all inequalities and non-negativity (x1,x2≥0x_1, x_2 \ge 0x1​,x2​≥0).
    3. Identify all corner (extreme) vertices.
    4. Evaluate objective function ZZZ at each vertex. The vertex giving max/min ZZZ is optimal.
  • Special Cases in Graphical Analysis:
    • Alternate Optima: Iso-profit line slope equals constraint line slope (- rac{c_1}{c_2} = - rac{a_{11}}{a_{12}}). Infinitely many optimal solutions exist along that edge.
    • Unbounded Region: Region open toward infinity with Zo∞Z o \inftyZo∞.
    • Infeasible Region: No region satisfies all constraints simultaneously.

3.3 — Transportation Model

1. Concept Pointers
  • Balanced vs Unbalanced:
    • Balanced if ∑Supply=∑Demand\sum \text{Supply} = \sum \text{Demand}∑Supply=∑Demand.
    • If Unbalanced, add a dummy row or column with zero unit shipping costs (cdummy=0c_{\text{dummy}} = 0cdummy​=0).
  • Initial Basic Feasible Solution (IBFS) Methods:
    1. North-West Corner Method (NWCM): Allocates strictly from top-left cell. Simple but ignores costs.
    2. Least Cost Method (LCM): Allocates to lowest cost cell first.
    3. Vogel’s Approximation Method (VAM): Calculates row and column penalties (difference between two lowest costs). Allocates to cell with highest penalty. Yields IBFS closest to optimum.
  • Non-Degeneracy Condition: Number of occupied (basic) cells MUST equal m+n−1m + n - 1m+n−1.
  • MODI Method (u-v Method) for Optimality:
    1. For basic cells: ui+vj=ciju_i + v_j = c_{ij}ui​+vj​=cij​ (set u1=0u_1 = 0u1​=0).
    2. For non-basic cells: Compute cell evaluation index Δij=cij−(ui+vj)\Delta_{ij} = c_{ij} - (u_i + v_j)Δij​=cij​−(ui​+vj​).
    3. If all Δij≥0  ⟹  \Delta_{ij} \ge 0 \impliesΔij​≥0⟹ Optimal solution reached (Minimization).
    4. If any Δij<0  ⟹  \Delta_{ij} < 0 \impliesΔij​<0⟹ Select most negative cell, construct closed loop, and reallocate.

3.4 — Assignment Problem (Hungarian Method)

1. Concept Pointers
  • Definition: Special case of Transportation problem where m=nm = nm=n and every source is assigned to exactly one destination (capacity =1= 1=1, demand =1= 1=1).
  • Matrix Attributes:
    • n×nn \times nn×n cost matrix.
    • Number of decision variables =n2= \mathbf{n^2}=n2.
    • Number of basic variables =2n−1= \mathbf{2n - 1}=2n−1 (highly degenerate by design).
  • Hungarian Method Algorithm (Minimization):
    1. Row Reduction: Subtract the minimum element of each row from every element in that row.
    2. Column Reduction: Subtract the minimum element of each column from every element in that column.
    3. Covering Zeros: Draw minimum number of horizontal and vertical lines (LLL) to cover all zeros.
    4. Optimality Check: If L=nL = nL=n, an optimal assignment exists among zeros.
    5. Matrix Adjustment (if L<nL < nL<n): Find smallest uncovered element kkk. Subtract kkk from all uncovered elements; add kkk to elements at line intersections; leave covered non-intersection elements unchanged. Repeat lines cover check.
  • Maximization Assignment: Convert to minimization by subtracting every element from the largest element in the matrix, then apply standard Hungarian method.

3.5 — Duality Theory & Shadow Prices

1. Concept Pointers
  • Primal–Dual Duality: Every LPP (Primal) has a dual formulation (Dual).
  • Symmetry: Dual of a Dual is the Primal.
  • Strong Duality Theorem: If Primal has an optimal solution Z∗Z^*Z∗, then Dual also has an optimal solution W∗W^*W∗, and Z∗=W∗Z^* = W^*Z∗=W∗.
  • Weak Duality Theorem: For any feasible Primal xxx and feasible Dual yyy, Z(x)≤W(y)Z(x) \le W(y)Z(x)≤W(y) (for Primal Max).
  • Unboundedness Property:
    • If Primal is Unbounded   ⟹  \implies⟹ Dual is Infeasible.
    • If Dual is Unbounded   ⟹  \implies⟹ Primal is Infeasible.
  • Shadow Price (yiy_iyi​):
    • Value of optimal dual variable yi∗y_i^*yi∗​.
    • Represents the marginal increase in optimal objective Z∗Z^*Z∗ per unit increase in resource bib_ibi​.
    • Indicates the maximum premium rate a firm should pay for extra units of resource iii.
