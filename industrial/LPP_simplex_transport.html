LPP, SIMPLEX & TRANSPORTATION
Exam Revision Guide for Competitive Exams

High-frequency topics: Graphical method (2-variable corner points), Simplex Tableau ($C_j - Z_j$, minimum ratio test), Slack/Surplus/Artificial variables (Big-M method), Transportation methods (NWCM, VAM, MODI $u\text{-}v$), Assignment problem (Hungarian algorithm).

1. Core Concepts & Definitions

1.1 Linear Programming Problem (LPP) — General Form

Maximize/Minimize: Z = c₁x₁ + c₂x₂ + ... + cₙxₙ

Subject to constraints:
  a₁₁x₁ + a₁₂x₂ + ... ≤/=/> b₁
  a₂₁x₁ + a₂₂x₂ + ... ≤/=/> b₂
  ...
  xᵢ ≥ 0 (non-negativity)

Components:
  • Decision variables: x₁, x₂, ..., xₙ
  • Objective function: Linear combination to optimize
  • Constraints: Linear inequalities/equalities
  • Feasible region: Area satisfying all constraints

1.2 Graphical Method (For 2 Variables)

Steps:
  1. Plot all constraint lines on 2D graph
  2. Shade feasible region (satisfies all constraints)
  3. Find corner points (vertices) of feasible region
  4. Evaluate objective function at each corner point
  5. Optimal solution at corner with best Z value

Insight: Optimal solution always at vertex (corner) of feasible region
         (or along edge if parallel to objective function)

1.3 Simplex Method (For Many Variables)

Simplex = Iterative algorithm to solve LPP with any number of variables

Key steps:
  1. Convert to standard form (add slack/surplus variables)
  2. Set up initial simplex tableau
  3. Identify entering variable (most negative in Cj-Zj row)
  4. Identify leaving variable (minimum ratio test)
  5. Perform pivot operation; repeat until optimal

Stopping condition: All Cj-Zj ≥ 0 (for maximization)
                   All Cj-Zj ≤ 0 (for minimization)

1.4 Slack, Surplus & Artificial Variables

Slack variable (s):
  Added to ≤ constraint to convert to equality
  Example: x₁ + 2x₂ ≤ 10 → x₁ + 2x₂ + s = 10
  Represents unused resource

Surplus variable (s):
  Subtracted from ≥ constraint to convert to equality
  Example: x₁ + x₂ ≥ 5 → x₁ + x₂ - s = 5
  Represents excess over minimum

Artificial variable (a):
  Added when ≥ or = constraints present (for initial basis)
  Uses Big-M method: penalty M in objective function
  Should be zero in final solution (removed from basis)

1.5 Transportation Problem (Specialized LPP)

Transportation Problem:
  • m sources (supply: S₁, S₂, ..., Sₘ)
  • n destinations (demand: D₁, D₂, ..., Dₙ)
  • Cost per unit: cᵢⱼ (from source i to destination j)
  • Objective: Minimize total transportation cost

Balanced: Σ Supply = Σ Demand (may need dummy source/destination)
Solution methods: NWCM, VAM, MODI method
Figure 1.3: Transportation Matrix — Unit Costs ($c_{ij}$), Supply ($S_i$), Demand ($D_j$), & VAM Initial Allocation.

1.6 Assignment Problem (Special Case of Transportation)

Assignment Problem:
  • n tasks, n workers
  • Each task assigned to exactly one worker
  • Each worker does exactly one task
  • Cost matrix given
  • Objective: Minimize total cost

Solution method: Hungarian algorithm

2. Essential Formulas & Principles

2.1 Objective Function & Standard Form

$$\text{Maximize } Z = \sum_{j=1}^{n} c_j x_j + 0 s_1 + 0 s_2 - M a_1$$

Slack variables have 0 coefficient; Artificial variables have $-M$ penalty coefficient ($+M$ for minimization).

2.2 Minimum Ratio Test (Leaving Variable)

$$\text{Minimum Ratio} = \min_{i} \left\{ \frac{b_i}{a_{ij}} \ \middle|\ a_{ij} > 0 \right\}$$

Where: $b_i$ = RHS column value, $a_{ij}$ = Pivot column entry ($a_{ij} > 0$). Determines which basic variable leaves the basis.

2.3 Transportation Problem Formulations

$$\text{Total Cost} = \sum_{i=1}^{m} \sum_{j=1}^{n} c_{ij} x_{ij}$$

Balanced condition: $\sum_{i=1}^{m} S_i = \sum_{j=1}^{n} D_j$. Number of basic cells in non-degenerate solution = $m + n - 1$.

2.4 Primal-Dual Relationships

Primal Problem (Maximization):
$$\text{Max } Z = \mathbf{c}^T \mathbf{x} \quad \text{subject to } \mathbf{A}\mathbf{x} \le \mathbf{b}, \ \mathbf{x} \ge \mathbf{0}$$
Dual Problem (Minimization):
$$\text{Min } W = \mathbf{b}^T \mathbf{y} \quad \text{subject to } \mathbf{A}^T \mathbf{y} \ge \mathbf{c}, \ \mathbf{y} \ge \mathbf{0}$$
Complementary Slackness:
  If primal variable $x_j > 0 \implies$ dual constraint $j$ is tight ($= c_j$).
  If dual variable $y_i > 0 \implies$ primal constraint $i$ is tight ($= b_i$).

3. Methods & Solution Approaches

3.1 Optimization & Transportation Methods Matrix

Method Use / Application Best For Exam Note

Simplex Algorithm Iterative tableau method; evaluates corner points systematically LPP with many variables (3+) Complex but systematic; standard industrial approach
Big-M Method Use artificial variables with large penalty (M) in objective LPP with ≥ or = constraints (not standard form) Artificial variables should exit in final solution
NWCM (North-West Corner) Simple heuristic for initial transportation solution Transportation problem; quick initial allocation Always feasible but not optimal; good starting point
VAM (Vogel's Approximation) Allocate based on penalty (difference in two lowest costs) Transportation problem; better than NWCM FREQUENTLY TESTED — often gives near-optimal
MODI Method (u-v Method) Optimality check for transportation; calculate dual variables Improve initial solution; test optimality Final optimization step; checks for improvement possibilities
Hungarian Algorithm Reduce cost matrix systematically; find zero-cost assignments Assignment problem (1-to-1 matching) Optimal solution guaranteed; specialized for assignment

3.2 Transportation Problem Solution Steps

Step Method Purpose
1. Check Balance Σ Supply = Σ Demand? If not balanced, add dummy source/destination with cost = 0
2. Initial Solution NWCM or VAM Allocate quantities to satisfy constraints; get basic feasible solution ($m+n-1$ allocations)
3. Test Optimality MODI method ($u_i + v_j = c_{ij}$ for allocated cells) Check if current solution is optimal ($c_{ij} - u_i - v_j \ge 0$)
4. Improve (if not optimal) Stepping stone method / Closed loop Reallocate quantities along closed loop to reduce cost
5. Repeat Steps 3–4 Until optimality condition satisfied (no negative opportunity costs)

4. Key Points to Remember

  • LPP has linear objective function and linear constraints. Both maximize and minimize forms; non-negativity required.
  • Graphical method for 2-variable LPP: plot constraints, shade feasible region, evaluate Z at corner points. Optimal at vertex or along edge.
  • Simplex algorithm iterates through feasible solutions using tableau; entering variable has most negative $C_j - Z_j$ (maximization). Minimum ratio test identifies leaving variable.
  • Slack variables added to $\le$ constraints; surplus subtracted from $\ge$ constraints; artificial variables added for $=$ or $\ge$ constraints using Big-M method.
  • Big-M method: artificial variables penalized with coefficient M (very large) in objective. Optimal solution has all artificial = 0 (removed from basis).
  • Transportation problem: Minimize cost subject to supply/demand; balance = $\sum \text{Supply} = \sum \text{Demand}$. Add dummy source/destination if unbalanced.
  • NWCM (Northwest Corner): Always feasible; allocate max possible from NW cell, moving right/down. Quick but not optimal; good starting point.
  • VAM (Vogel's): Allocate based on penalty (cost difference); often gives near-optimal solution. FREQUENTLY TESTED.
  • MODI method ($u\text{-}v$ method): Calculate dual variables ($u_i, v_j$) at allocated cells; opportunity cost $d_{ij} = c_{ij} - (u_i + v_j)$; negative indicates improvement opportunity.
  • Assignment problem = special transportation ($n \times n$ matrix, each row/column sum = 1). Hungarian algorithm guarantees optimal 1-to-1 matching.
  • Complementary slackness: If primal variable $> 0$, dual constraint tight (equality). Links primal and dual solutions.
  • Degenerate solution: Fewer than $m+n-1$ basic variables in transportation problem. Requires adding $\epsilon$ to unallocated cell.
  • Optimality condition (transportation): All opportunity costs $d_{ij} \ge 0$ (no unallocated cell improves solution). MODI method checks this.
  • Sensitivity analysis: Shadow price (dual value) shows $Z$ improvement per unit resource increase. Ranges given for coefficient/RHS changes.
  • Unbounded solution: Objective can increase indefinitely (no constraint limits growth). Infeasible solution: No feasible region exists (contradicting constraints).
